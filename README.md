# Kanagawa Dragon

A dark, earthy VS Code colour theme based on the **Dragon** variant of the [Kanagawa](https://github.com/rebelot/kanagawa.nvim) colour scheme by rebelot.

## Install

Install from the packaged VSIX:

```
code --install-extension kanagawa-dragon-1.0.0.vsix
```

Or in VS Code: **Extensions** → `...` menu → **Install from VSIX...**

Then choose the theme: `Ctrl+K Ctrl+T` → **Kanagawa Dragon**.

## Build

```
npx @vscode/vsce package
```
